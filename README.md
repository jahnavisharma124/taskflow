# TaskFlow - Project & Task Management Tool

Full-stack project management app: React, Node.js/Express, MySQL, Python reports.

## Setup (backend)
1. Run `database/schema.sql` in MySQL.
2. `cd backend && cp .env.example .env` and fill in your values.
3. `npm install`
4. `npm run dev`
5. Visit http://localhost:5000/api/health
